## 署名如何阅读

- **发帖者**：发布这条 X/Reddit 帖子的账号。这不自动意味着其创作了视频。
- **原始视频创作者**：只有证据支持时才标注；否则诚实显示为未知。
- **提示词作者**：与发帖者、视频创作者独立记录；转载提示词不会改变作者身份。
- **网友注释**链接具体评论及评论者；**仓库编辑注释**则标明编辑身份和审核依据。
